# Internacionalização

O app usa **vue-i18n 9** com 19 idiomas. Nenhuma string visível ao usuário deve
ficar hard-coded em componente.

## Arquivos

- `src/assets/languages/<código>.json` — um arquivo por idioma
- `src/assets/languages/languages.js` — importa e registra todos; exporta
  `languages` e `defaultLocale = 'en'`
- `src/helpers/languageHelper.js` — lista exibida na tela de configuração
- `crowdin.yml` — configuração da plataforma de tradução usada pelo upstream

Idiomas atuais: `en`, `es`, `ru`, `fr`, `pt`, `zh-CN`, `zh-TW`, `de`, `it`,
`ar`, `pl`, `ja`, `tr`, `uk`, `ko`, `hi`, `he`, `vi`.

**Atenção:** os arquivos `zh-CN.json` e `zh-TW.json` são importados como
`zh_cn` e `zh_tw` em `languages.js`. A chave usada no `config.language` é a do
objeto exportado, não o nome do arquivo.

## Seções do `en.json`

`settings` · `donate` · `about` · `generatedData` · `tips` · `welcome` · `ui` ·
`todoDetails` · `notifications`

`generatedData` são os textos das tarefas de exemplo criadas no primeiro uso
(`helpers/initialDataCreator.js`).

## Adicionando uma string nova

1. Escolha a seção adequada e acrescente a chave em **`en.json`**.
2. Replique a chave em **todos os outros 18 arquivos**. Uma chave ausente cai no
   fallback (`en`), o que funciona, mas deixa a interface misturada.
3. Use no template com `{{ $t('secao.chave') }}` ou no script com
   `this.$t('secao.chave')`.

Script útil para verificar chaves faltando:

```bash
python3 - <<'PY'
import json, glob, os
base = json.load(open('src/assets/languages/en.json'))
def flat(d, p=''):
    for k, v in d.items():
        yield from flat(v, f'{p}{k}.') if isinstance(v, dict) else iter([f'{p}{k}'])
ref = set(flat(base))
for f in sorted(glob.glob('src/assets/languages/*.json')):
    if f.endswith('en.json'): continue
    faltando = ref - set(flat(json.load(open(f))))
    if faltando:
        print(os.path.basename(f), '->', len(faltando), 'faltando:', sorted(faltando)[:8])
PY
```

## Adicionando um idioma

1. Crie `src/assets/languages/<código>.json` a partir do `en.json`.
2. Importe e registre em `languages.js`.
3. Acrescente à lista de `src/helpers/languageHelper.js` para aparecer nas
   configurações.
